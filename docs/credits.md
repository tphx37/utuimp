## Services

- **Yandex Music** support is based on the unofficial API documented by
  [MarshalX/yandex-music-api](https://github.com/MarshalX/yandex-music-api)
  and [oklookat/goym](https://github.com/oklookat/goym).
- **Spotify** uses the
  [Spotify Web API](https://developer.spotify.com/documentation/web-api) and
  plays through [librespot](https://github.com/librespot-org/librespot).
- **YouTube Music and SoundCloud** play through
  [yt-dlp](https://github.com/yt-dlp/yt-dlp) and
  [FFmpeg](https://ffmpeg.org). SoundCloud can also use the
  [SoundCloud API](https://developers.soundcloud.com/docs/api/guide).
- **Apple Music** uses MusicKit.

## Lyrics

[LRCLIB](https://lrclib.net), NetEase Cloud Music,
[lyrics.ovh](https://lyrics.ovh) and Yandex Music.

## Interface and sound

- [Bubble Tea](https://github.com/charmbracelet/bubbletea) and
  [Lip Gloss](https://github.com/charmbracelet/lipgloss) for the interface
- [GStreamer](https://gstreamer.freedesktop.org/) for the sound on Linux
