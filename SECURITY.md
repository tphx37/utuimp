# Security Policy

This project is maintained by [tphx37](https://github.com/tphx37).

## Supported versions

Security fixes are provided for the latest release. Please update to the
latest version before reporting an issue, if possible.

## Reporting a vulnerability

Please report security vulnerabilities privately through GitHub:

1. Open [Report a vulnerability](https://github.com/tphx37/utuimp/security/advisories/new).
2. Describe the issue, the affected version, and the steps needed to reproduce
   it. Include any relevant logs after removing credentials and personal data.
3. Submit the report. The maintainer will review it and respond through the
   private advisory.

Please do not disclose vulnerabilities in public issues, discussions, or pull
requests before a fix is available. Never include tokens, cookies, passwords,
client secrets, or your configuration and credentials files in a report.

If the report is accepted, the maintainer will work on a fix and coordinate
disclosure with you. If it is declined, the maintainer will explain why in
the private advisory. Response and fix times depend on the issue and
maintainer availability.
